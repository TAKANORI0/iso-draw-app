# 現場アイソメ（iso-draw）— 配信用

プラント配管の現場で、指でなぞってアイソメ図（等角投影図）を描き、
寸法・切寸を出して SketchUp へ渡すためのタブレット用アプリです。

**このリポジトリはビルド成果物の置き場**で、GitHub Pages から配信するためだけにあります。
ソースは別で管理しています。

## 使う

<https://takanori0.github.io/iso-draw-app/>

## オフラインで使う（現場向け）

1. 電波のあるところで上の URL を Chrome で開く
2. メニュー →「アプリをインストール」/「ホーム画面に追加」
3. 以後は**圏外でも起動**します。外部への通信はありません

図面は端末の中（IndexedDB）に保存されます。サーバーには何も送りません。

## 中身

- Flutter（Web ビルド・CanvasKit をローカル同梱）
- 継手の寸法データは JIS 系の公開寸法表（TS / DV / ねじ込み / 突合せ溶接）
- 描いた線は 3D のノード列として保持し、寸法は芯々。切寸は継手の引き寸法を引いて都度計算します

## ライセンス

同梱している第三者ソフトウェアの表示は `assets/NOTICES` にあります。
